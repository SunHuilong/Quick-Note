# 快记 · Quick note — 发布文案

## 名称

快记 · Quick note

## 简介

桌面悬浮待办，随手快记。快记（Quick note）是一款轻量 Todo 与桌面便签工具，随手记录任务清单、工作琐事和临时想法，按天整理时间线，一键勾选完成。无需创建项目或选择分类，记下就能接着做事，回看也有迹可循。

## 介绍

**快记 · Quick note**  
**随手记一笔，做完勾一下。**

工作中突然想到的小事、临时需要跟进的任务、怕转头就忘的想法，都可以先放进快记，再继续手头的事情。

快记是一款轻量的桌面待办工具，用悬浮快贴承接日常记录，用时间线帮你回看每一天。

### ✍️ 想到就记，省去整理的准备

无需创建项目，也不用先选分类。输入内容，按下 Enter，就能加入今天的待办；需要多写几句，也支持换行记录。

### 📌 放在桌面，随时看一眼

快贴支持置顶、拖动和调整大小，放在你顺手的位置。完成一件，勾选一件；已完成事项可以划线保留，也可以隐藏，让眼前的清单保持清爽。

可以设置启动时自动打开快贴；运行中再次打开插件，会显示时间线主界面。修改内容后点击外部或按 Enter 即可保存。

### 🗓️ 按天回看，留住事情的来处

记录按创建日期分组，主界面每天一列，从今天向过去浏览。

昨天记下的事，即使今天才完成，也仍然留在昨天。回头看时，既能找到那条记录，也更容易想起当时的情况。

### 适合放进快记的事

- 工作间隙冒出的临时任务
- 等会儿需要回复、确认或跟进的小事
- 日常备忘、生活琐事和零散想法

你可以把它当作简单的 Todo 待办清单，也可以搭配已有的任务管理工具，专门收下那些随手需要记住的事情。
